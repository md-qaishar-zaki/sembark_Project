# sembark - React TypeScript E-Commerce App

A simple e-commerce application built with React, TypeScript, and React Router.

## Features

### Product Listing Page
- Display all products
- Category filter
- Price sorting
- Filter state preserved after page refresh

### Product Detail Page
- Dynamic routing using product id
- Product title
- Product description
- Product price
- Add to My Cart functionality

### Cart Page
- Add products to cart
- Increase quantity (+)
- Decrease quantity (-)
- Remove product from cart
- Total items count
- Total price calculation

### Cart Persistence
- Cart data stored in Local Storage
- Cart remains available after page refresh

## Tech Stack

- React
- TypeScript
- React Router DOM
- CSS
